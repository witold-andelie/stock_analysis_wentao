# Stock Market Analytics Zoomcamp — Homework 1 (Module 1)

> 本 README 仅对应 **Homework 1（Module 1, 2026 cohort）**，不覆盖后续其他作业。

Solutions for Homework 1 (2026 cohort) of the [Stock Market Analytics Zoomcamp](https://github.com/DataTalksClub/stock-markets-analytics-zoomcamp).

This homework covers S&P 500 composition changes, global index returns, historical
corrections, and earnings-surprise based event studies. All analysis is
reproducible from the scripts in this repository.

## Answers (summary)

| Question | Answer |
| --- | --- |
| **Q1** — Which year had the most additions to the S&P 500 since 2020? | **2025** — 18 additions. |
| Q1 bonus — How many of today's constituents have been in the index for more than 20 years? | **227** current members. |

Machine-readable versions of these answers are written to
`data/outputs/answers.json` when you run the pipeline (see below). The
cached datasets and output files are generated at run time and are **not**
committed to this repository.

### Q5 (exploratory, free text) — capstone idea

> Short-horizon momentum + earnings-drift strategy for US mega-cap tech stocks.
> Idea: rank the ~50 largest US-listed tech stocks by blended momentum (price
> vs. 20/50/200-day MAs) plus post-earnings announcement drift (PEAD); train a
> gradient-boosted classifier to predict a positive 10-day forward return and
> backtest a top-quintile monthly-rebalanced portfolio. Data would combine
> yfinance price history with regular earnings calendar/surprise data. The
> earnings-surprise event study in Q4 is a building block for this idea.

## How to run

Requirements: Python 3.10+, `pandas`, `numpy`, `requests`, `pyarrow`, `yfinance`
(and `plotly` for the charts).

```bash
# All commands are run from the repository root.

# 1. Run the full analysis (including bonus steps) and print the answers
python homework1/solution.py

# 2. Skip the bonus steps (faster; bonus questions are marked in the output)
python homework1/solution.py --skip-bonus

# 3. (Optional) Rebuild the charts / dashboard after re-running the analysis
python homework1/scripts/make_charts.py
```

### Caching & network

- Raw datasets are cached as parquet files in `homework1/data/raw/`. Re-runs
  read the cache and do **not** hit the network unless a cached file is missing.
- To force a fresh download, simply delete the corresponding parquet file, e.g.
  `rm homework1/data/raw/q2_world_indices_ytd.parquet`.
- The default analysis window is the homework 1 period (2026 YTD up to the
  homework cutoff date). Answers that depend on live data (e.g. YTD index
  returns) will change as the market moves — the cached snapshot pins them for
  reproduction.

## Notes

- Q1 uses the Wikipedia list of S&P 500 index changes (each current
  constituent's "added to index" date), grouped by year of addition.
- Q2 comparisons use daily closing prices of the price-only indices
  (^GSPC vs. the other world indices), per the assignment; currency effects are
  ignored.
- Q3 analyzes S&P 500 daily closes from 1950 onward; a correction is defined as
  a drawdown of ≥ 5% from the running all-time high.
- Q4 matches yfinance earnings calendar data (expected/reported EPS, surprise %)
  with 3-day rolling windows of AMZN price history to compute 2-day returns.
